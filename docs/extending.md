# 扩展指南

元探长个人版完整开源，从服务器运营版的四个模块适配而来，保留界面、子页面和操作入口。原平台商业用户账号运营体系、原付费 API 调用及其实现由线上版单独维护，不包含在个人版中；对标博主档案、作品关联与绑定界面仍然保留。

我们希望这份源码既能用于个人工作，也便于按自己的需求继续改造。演示浏览、手工录入原文与本地文件导入、资料管理、编辑和版本保存可按[安装说明](installation.md)直接使用；实际抓取、AI 生成与分析、音视频转写和自动调度需要自行接入。

## 推荐的采集接入路径

优先使用自己运行的本机脚本或浏览器自动化，取得有权访问的页面内容。将程序按[本机采集合同](local-collector.md)封装为 HTTP 服务并独立启动，再到 **采集调度 → 采集设置** 填入地址。输入来源链接并点击“开始采集”后，工作台会调用该程序、校验结果并保存素材，无需改动界面。

这里的本机指 **API 运行的电脑**。程序需要独立保持运行；平台抓取和自动调度由自己的程序实现，工具不内置平台抓取器或自动采集定时器。采用这条路径可以不采购按次计费的商业采集 API，仍需考虑设备、网络及所选模型等成本。

AI 模型可以辅助解析或分析已取得的内容，不能代替采集程序。通用采集接口接收素材正文；AI 生成、分析和音视频转写需另外实现对应的处理逻辑，并保留来源、真实处理状态和可保存的结果。

## 扩展时保留的业务约定

- 业务操作由服务端验证个人身份与工作空间归属。
- 页面加载、筛选、保存不能隐式开始外部操作。
- 长任务应有真实状态、取消与错误处理；重试不得产生重复结果。
- 新内容通过原业务服务建立关系，草稿更新保留版本校验。
- 外部内容、文件路径和 URL 按不可信输入校验，凭据不发送给浏览器或写入日志。
- 未接入或执行失败应准确反馈，不能退回演示结果并声称已完成。

完成扩展后，使用独立测试数据验证导入、重复处理、失败重试和结果保存，再用于自己的日常资料。
