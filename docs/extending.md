# 扩展边界

个人版从服务器运营版的四个模块适配而来，保留界面、子页面和操作入口。本地内容管理与创作流程有完整业务实现；线上商业账号管理和付费服务接入由线上版单独维护，未纳入本次发布。

我们希望这份源码既能用于个人工作，也便于按自己的需求继续改造。浏览、录入、编辑、保存和文件管理可按安装说明使用；外部抓取、分析、生成等处理能力由使用者选择并实现。

自动采集可以由自己运行的本地脚本或浏览器自动化完成，再把合法取得的内容接入现有业务存储。只处理有权访问和使用的内容；不要让抓取程序绕过账号权限或无限制访问任意内网地址。

仓库提供通用[本机采集程序接入](local-collector.md)，可以显式调用自己的 HTTP 程序并保存返回内容，不必修改工作台界面。本机指 API 运行电脑；需要自行实现、启动采集程序，平台抓取与自动调度也由该程序负责。

AI 模型可以作为解析或分析的一步，不能代替采集程序、有效访问权限、失败处理和持久保存。接入后应明确区分“取得内容”和“模型推断内容”，保留来源与处理状态。

修改时遵守以下合同：

- 业务操作由服务端验证个人身份与工作空间归属。
- 页面加载、筛选、保存不能隐式开始外部操作。
- 长任务应有真实状态、取消与错误处理；重试不得产生重复结果。
- 新内容通过原业务服务建立关系，草稿更新保留版本校验。
- 外部内容、文件路径和 URL 按不可信输入校验，凭据不发送给浏览器或写入日志。
- 未接入或执行失败应准确反馈，不能退回演示结果并声称已完成。

这里提供接口和改造边界，不附带平台抓取器、模型服务或线上接口额度。服务权限、凭据和运行资源需要按自己选择的方案准备；这些内容不会因为下载源码而自动取得。完成扩展后，在自己的隔离环境验证再使用。
