# 页面与功能地图

工作台入口为 `/workspace/viral`，`view` 查询参数选择主视图。本文使用“对标中心”和“采集库”描述业务范围，界面保留现有“对标账号”“采集仓库”等标签。

| 主板块 | 路由视图 | 主要内容 |
| --- | --- | --- |
| 情报中心 | `overview` | 内容概览、平台分布、关注方向、可继续创作的内容。 |
| 创作中心 | `topics` | 选题库与情报流、素材选择、进入稿件。 |
| 对标中心 | `accounts` | 对标博主档案、平台身份、作品关联和筛选。 |
| 采集库 | `works` | 素材列表、平台与作者筛选、内容详情和导入。 |

## 创作与研读子页面

创作中心的情报流、稿件列表、原稿、爆款拆解、编辑器和参考播放器是完整工作流程的一部分。保留其页签、抽屉、表单、菜单、弹窗和返回路径，不用静态截图代替界面。

- 从素材或选题打开已有稿件；没有对应稿件时建立新稿件。
- 查看原文、来源、笔记和已有拆解。
- 编辑标题和正文，保存、重新读取并查看版本。
- 在编辑器和播放器之间切换，保留参考关系。
- 打开绑定、设置与其他既有子界面；保存本地业务配置或给出准确的能力状态。

`material` 和 `draft` 等查询参数用于定位内容。URL、列表选中项和当前编辑对象应保持一致；返回主页面不应错误覆盖尚未保存的编辑。

## 对标与素材子界面

保留账号资料编辑、平台信息、备注、关联作品、详情、筛选和批量选择。业务中的“对标账号”是内容对象，与平台经营者管理注册用户的运营体系不同。

素材导入保留链接、粘贴原文、上传文件等界面。保存链接表示保存来源记录，不能自动等同于已取得正文；本地媒体文件保存也不能自动等同于已转写。

## 共同操作

工作台导航、侧栏收起、平台筛选、搜索、分页、隐私遮罩、阅读状态、删除恢复、状态栏与操作反馈继续使用真实数据和实际状态。

外部抓取、分析、生成等入口保留。没有接入实现时明确提示当前能力不可用；其页面上的已有案例与人工输入内容仍可查看和编辑。

## 关联页面

这些页面承接四板块内已有的操作入口，不增加新的主导航板块。

| 路由 | 用途 |
| --- | --- |
| `/workspace/creation` | 内容项目列表与创作工作台，从创作中心的“内容项目”进入。 |
| `/workspace/creation/[id]` | 单个内容项目，包含母稿、来源与制作信息、保存和版本相关操作。 |
| `/workspace/knowledge` | 本地名单来源管理，保存逐行博主主页链接，供对标中心预览与导入。保留“知识沉淀连接管理”的入口标签。 |
| `/workspace/settings` | 个人设置与演示资料管理。 |

本地名单页面只管理自己录入的名单，不表示已接通其他知识库或外部同步。内容项目继续通过个人会话访问，同样校验工作空间归属。

## 演示内容

首次初始化提供少量合成账号、素材、选题、拆解和稿件，覆盖相互关联的浏览路径。名称、原文、数字和插画都是演示材料，不表示真实作者或平台结果。

演示资料使用普通业务界面，可以打开、筛选、编辑和保存。没有强制教学流程；是否清除案例由使用者决定。清理规则见 [日常使用](usage.md)。
