# 个人版设计系统

本文件约束四板块及其子页面的视觉与交互。实现以随项目提供的组件和样式为准；修改设计时，应同步更新文档和对应验证记录。

## 视觉目标

保留完整内容工作台的布局、层级和操作路径。四个主板块共用外壳、导航、字体、主题与状态；创作、阅读、对标和素材管理保持各自适合业务的主内容结构。

页面顶部只保留采集调度入口，平台与转写状态集中在调度页。八个平台状态和转写状态不再作为每个页面顶部的重复徽标展示。

采用中性表面、清晰文字和蓝色主要交互。浅色与深色各自保留页面、内容、侧栏、卡片、输入和浮层的层级。颜色运行值统一来自 `styles/ui-theme.css`，不要在组件中另建色板。

| 角色 | 用法 |
| --- | --- |
| 页面与侧栏 | 中性底色，侧栏和内容区通过表面层级区分。 |
| 正文与辅助文字 | 分别使用正文和弱化文字 token；错误、未知值与真实内容分开。 |
| 蓝色 | 品牌、主要操作、链接与键盘焦点。 |
| 状态色 | 成功、警告、错误分别使用语义 token，不承担普通装饰。 |
| 雷达点缀 | 局部低饱和信号装饰，不能替代正文对比度。 |

## 字体与字阶

英文和数字使用项目自托管 Inter，中文使用 Noto Sans SC，CSS 家族名可保留 `Radar Sans SC`。不依赖用户系统安装，不按操作系统改变主字体。字体缺失需修复，不用缩放整个界面补偿。

- 常规正文 14px，辅助信息 12px；标题按现有组件层级使用 17–24px。
- 导航文字常规桌面 14px / 500，大桌面与手机 16px / 500，选中为 600。
- 数字计数优先使用等宽数字，未知计数显示 `—`。
- 正文建议行高 1.6–1.8；编辑正文按内容角色保留更舒适的行距。

## 布局与滚动

桌面主要对照尺寸为 **2560 × 1440 CSS 像素、100% 缩放**。同时检查 1440 × 900 和手机布局，截图记录实际视口、主题与设备像素比。

| 范围 | 768–1799px | ≥1800px | ≤767px |
| --- | --- | --- | --- |
| 侧栏 | 200px | 240px | 可收起抽屉，保留内容操作区 |
| 主导航点击区 | 至少 44px | 至少 48px | 至少 48px |
| 图标 / 图文间隔 | 20px / 10px | 20px / 10px | 20px / 10px |
| 导航圆角 | 10px | 10px | 10px |

同排同类面板由布局决定尺寸，不随条目数量伸缩。标题、筛选、工具和主要操作保持位置，中间列表或正文内部滚动。设置 `min-width: 0`、`min-height: 0` 并正确开放滚动，不裁掉末项。

双栏创作区保留选题与情报流的关系；稿件视图保留编辑与参考区。手机使用既有面板切换，不通过缩小字体或整体缩放把桌面界面塞进手机。

## 组件约定

- **按钮：** 主要操作有明确优先级；次要按钮保持中性。加载时给出文字状态并防止重复提交。
- **表单：** 输入有可理解的名称、帮助与错误位置；错误不清空用户输入。多行内容在自己的编辑区滚动。
- **页签：** 切换后保留同一外框和内容上下文，键盘可操作，选中状态可被辅助技术读取。
- **列表与表格：** 标题、来源、作者、状态和操作顺序稳定；长标题可读，统计和原始内容分开。
- **弹窗与抽屉：** 打开有合理焦点，关闭可返回触发位置；忙碌时避免丢失正在提交的内容。
- **播放器：** 缺少媒体时保留正常布局与状态说明，不假装已经得到可播放文件。
- **演示案例：** 用简短标签标明演示，作为普通内容直接浏览和编辑，不增加教学遮罩或强制引导步骤。

## 状态与能力

每个数据区域区分加载、空、无搜索结果、失败、已有内容和版本冲突。切换这些状态时保持布局稳定。

外部处理入口完整保留。未接入的操作明确显示“当前版本未接入此项外部处理能力”，不伪造成功、任务进度、处理结果或指标。对已导入的拆解、稿件和参考内容，仍提供正常查看、编辑与保存。

## 无障碍与动态效果

普通文字对比度目标至少 4.5:1，必要控件与大文字至少 3:1。焦点清晰可见；图标按钮有名称，状态提示使用适当的 live region。选中和错误不能只靠颜色表达。

交互动效以短暂状态反馈为主，尊重 `prefers-reduced-motion`。避免让动效改变表单可用性或掩盖真实请求状态。

## 修改后的对照

比较相同视口、主题、页面、数据量和操作状态。检查主页面与稿件、拆解、绑定、详情等下级界面；确认全部入口仍然可达。编译、类型检查和截图各自证明不同事项，不能相互替代。
