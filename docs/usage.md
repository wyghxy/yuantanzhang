# 日常使用

## 浏览案例

首次初始化后，四个板块中已有少量标记为“演示”的虚构资料。可以直接打开素材、对标档案、选题、拆解和稿件，使用正常的筛选、切换、编辑及保存操作。

案例插画为项目原创几何绘图，数字和文字用于展示内容关系，不代表真实平台抓取结果。它们不是教学弹窗，也不需要完成引导步骤。

## 收录自己的内容

使用素材导入入口粘贴原文，或者上传本地文本、字幕、音视频文件。保留来源、作者、标题等信息，方便在创作时追溯。

链接可以作为来源记录；拥有链接并不表示已经取得正文或媒体。音视频上传成功表示文件已保存，不表示语音已经识别完成。

## 研究对标

维护博主资料、平台身份与备注，并将相关素材关联到对应档案。对标账号是内容工作台中的业务对象，个人登录账号是访问保护，两者不互相替代。

根据自己输入的资料筛选和查看。没有取得的指标保留未知状态，不用零或演示数字填充真实记录。

## 选题与写稿

从素材或选题进入创作，查看原稿、已有拆解与参考内容，编辑自己的标题和正文。保存后可以重新打开读回。

遇到版本冲突时，先比较当前内容和自己的编辑，再决定如何合并；不要用刷新页面作为覆盖另一份内容的办法。离开编辑界面前留意未保存状态。

## 外部处理

界面保留抓取、分析、生成等相关入口。当前没有接入相应实现时，会明确提示未接入，不会将案例或固定文本作为本次处理结果。

如需自行接入，参阅 [扩展边界](extending.md)。配置一个 AI 模型不自动等于具备采集能力；采集、解析、分析和存储需要由实际代码完成。

## 演示资料管理

```bash
pnpm demo:seed
pnpm demo:clear
```

前者在尚未初始化的工作区添加一次演示案例，重复执行不会重复插入，清除后也不会自动重建。后者只处理明确标记的演示资料。清除前先保留需要继续使用的内容；修改演示条目并不当然把它转换成个人资料。

日常内容使用新建记录保存。不要把演示清理当成通用数据库重置或删除全部内容的命令。
