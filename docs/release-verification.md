# 0.1.0 本地验证回执

验证日期：2026-11-07。环境为 Node.js 22.23.2、pnpm 9.15.9、PostgreSQL 16、Redis 7、本地 Chromium；使用独立数据服务和合成案例。

| 检查 | 结果与范围 |
| --- | --- |
| 冻结依赖安装 | `pnpm install --frozen-lockfile --offline --ignore-scripts` 通过。 |
| 类型与静态检查 | 全部工作区类型检查和 ESLint 通过，无错误或警告；自维护源文件 900 行检查通过。 |
| 构建 | Nest API、Worker、Next.js 生产构建通过，包含四块工作台与内容项目、名单、个人设置路由。 |
| HTTP 基础流程 | 11 组断言通过：登录、会话保护、录入、关联、版本冲突、上传下载、跨站拒绝、删除恢复及退出。 |
| 后端工作流 | 5 组通过：原文与安全显示、素材关联撤销和分镜文件、名单预览确认、母稿与定稿交接、Redis/BullMQ 到独立 Worker 的本地任务。 |
| 富文本保存 | 模板及稿件 JSON 的段落、粗体和锚点，保存后重新读取并深比较通过。 |
| 演示清理 | 真实数据库事务中验证：只删除演示标记记录，保留个人记录；验证完成回滚事务。 |
| 浏览器 | 四主视图、拆解、稿件、实际编辑保存重载、内容项目、深色及手机布局通过；无页面运行错误。平台与转写状态集中在采集调度页，普通页面顶部不再显示。 |
| 本地运行边界 | 浏览器验证阻断外部请求；已验证流程未产生外部请求。 |
| 资料与许可 | 原创演示内容、本地字体与 SVG、MIT 原文、两份 OFL 及第三方声明齐全。 |

本回执说明本次本地验证的范围，不代表外部处理能力已接入，也不代表未来每个浏览器版本和用户自行修改的实现均已验证。持续集成配置已提供；远端运行结果以实际工作流记录为准。
