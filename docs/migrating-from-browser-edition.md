# 从旧浏览器版升级

0.2.0 使用 Next.js 前端、NestJS 后端和独立 PostgreSQL。旧浏览器版使用当前浏览器来源下的 IndexedDB；两者的数据存储位置不同，不会自动互相读取。

升级前，在原来的浏览器、域名和端口打开旧工作台 `/desk/`，导出 JSON 备份，并导出需要继续创作的 Markdown 或正文。确认备份文件可以读取后，再安装新版本。不要为了升级清空浏览器站点数据。

旧版本可从 [固定提交](https://github.com/wyghxy/yuantanzhang-community/tree/40f47f3b0a8681d122658d4d7e5e4d34b477fd87) 或 `legacy-browser-v0.1.0` 标签取回。它继续保留原来的源码、许可和导出工具，便于读取原资料。

在新版本中，按安装文档建立自己的数据库与登录账号，通过素材导入入口收录正文或本地文本文件。旧版 JSON 作为完整恢复备份保留；目前没有自动把旧版 JSON 的全部笔记、ID 和关联转换到 PostgreSQL 的迁移器，不能将导出文件直接覆盖进新数据库。

新版本的默认端口为 3310。更换端口或启动新版本不会替你删除旧浏览器的数据，但也不构成对那些数据的备份。原先的字体和编辑器等第三方材料仍遵守对应许可。
